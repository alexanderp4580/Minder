Minder

Purpose

Minder is a personal assistant for tasks, lists, reminders and schedules. The interface is black and red. Each element shows information or gives an action.

A

Information first

The edge column shows a count or a time. The brackets mark the most urgent item. Every mark has a reason.

B

Red means urgent

Signal red has five uses: the focus frame, overdue state, the main action, the selected state and live recording. Six label colours tag items. All other parts are black, white or grey.

C

Wide and angular

The design uses corner brackets, a vertical edge column, wide letters and one cut corner on the main button.

Where Signal red appears

Signal red marks urgent state and the main action. Use it only for the five uses below. All other parts are neutral.

Rules

  • Show an icon next to a text label. Use the Text colour or the button text colour.

Move

Move changes the column or the list of a card. It must not look like Open. Move shows the two-way horizontal arrows. Open shows the diagonal arrow.

Selected state

A selected control shows a fill. A selected segment or filter chip has a Signal fill with White text (4.9 : 1). The active tab has a Signal icon and a 2 px Signal bar.

09/10Voice

Voice

Write short, direct sentences in English.

FieldRuleExample
TitleUse one or two words. State the situation.Today
Section labelUse capitals and 12 px or more. Name the status or the kind of information.MOST URGENT · OVERDUE
MetaUse mixed case and 12 px or more.Home · Chore
BodyWrite one line in sentence case. Give the item title.Pay tax bill
ButtonsUse one word.Done

Writing style

Write at about 80% of ASD-STE100. This applies to all text the user reads: notifications, assistant messages, digests, error messages and the interface. Use sentences of 20 words or fewer. Use the active voice and simple tenses. Use one word for one meaning. Give instructions as commands. The exact rules: to check against the official ASD-STE100 specification.
