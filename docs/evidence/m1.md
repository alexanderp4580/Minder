## Code review of the branch (2026-11-12)

Fixed, each with a test that failed first:
- Done on a reminder for a repeating item finished it for good, while Done in chat rolled it forward. `domain.Complete` now serves both paths and the notification.
- The model context held every item, finished ones too, so a long-lived database would exceed the request limit. It now holds at most 200 open items.
- A reply from the model that hit the 1,000-token output cap was cut off mid-JSON and failed as "proposal unreadable". The cap is 4,000 and a cut-off reply is a clear model error. Found by running the real model five times; the check is now `toolchain/real-model-multi-check.py`.
- An invalid item status and every store failure surfaced as `model_error` or a generic 500. Codes now name the cause (`internal_error`, `model_error` as 502, `invalid_field`).
- A panic in the assistant goroutine would have stopped the whole server. It now becomes an error entry.
- When moving an item that only has a deadline, the model added a `start_at` after it. The prompt now says to move the field the item already uses.

Restructured:
- Routes: one pattern table in `api.New` replaces two hand-written parsers. `GET /v1/health` no longer returns a stale version.
- Schema: `store/migrations/NNN_*.sql` with `PRAGMA user_version`, tested for an old database and for a newer one.
- One helper loads JSON rows. The system prompt moved from an inline 2 KB string to `assistant/prompt.go`. The preview's field list is a readable table.
- App: `Change` and `ReminderInfo` are typed models, with no raw map access in the UI. `EntryView` replaces a 200-line method in the chat screen.
- Formatting: my earlier format calls used wrong paths and did nothing. Six Go files and seven Dart files were unformatted. Both formatters now report clean, and the check is in the AGENTS files.

Left as is, for the owner to decide:
- `cmd/minder/main.go` holds the Cloudflare issuer, audience and owner email as defaults. Moving them to required settings means setting three variables on Coolify first.
- The event stream polls the database every 200 ms for each open connection. That is fine for one owner.
