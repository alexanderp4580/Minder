# Minder

Personal planner, task manager and assistant. One chat screen in a Flutter app (Android and web) is the whole interface. You talk to it by text or voice. Single user, self-hosted, at most €10 per month to run.

Requirements: [docs/requirements.md](docs/requirements.md). First build slice: [docs/m0-spec.md](docs/m0-spec.md). Brand guide: [brand/index.html](brand/index.html).
